## Featured ML & AI Projects

### 1. [Predictive Maintenance AI Platform](https://github.com/XxCPH4xX/Predictive-Maintenance-AI-Platform)

An end-to-end machine learning workspace for estimating equipment failure risk and exploring the factors behind individual predictions.

- **ML workflow:** Data auditing, preprocessing, leakage prevention, baseline comparison, model selection, and held-out test evaluation.
- **Explainability:** SHAP-based global and individual explanations for model predictions.
- **Application:** FastAPI inference service with a Next.js dashboard for single predictions, batch CSV analysis, simulated fleet views, and performance reports.
- **Evaluation:** The documented held-out test results include 85.29% recall and 0.9806 ROC-AUC. The selected validation operating threshold did not fully achieve its target recall on the test set.

**Technologies:** Python, Pandas, NumPy, scikit-learn, XGBoost, SHAP, Jupyter, FastAPI, Next.js, React, TypeScript.

### 2. [Chest X-ray Pneumonia Classification](https://github.com/XxCPH4xX/Chest-X-ray-Pneumonia-Classification)

An educational deep learning project that classifies chest X-ray images as `NORMAL` or `PNEUMONIA` and visualizes model influence.

- **Model:** PyTorch and a pretrained ResNet18 backbone for image classification.
- **Interpretability:** Grad-CAM visualizations to inspect image regions influencing predictions.
- **Evaluation:** The documented held-out test results report 87.66% accuracy and 94.49% ROC-AUC.
- **Application:** FastAPI backend and Next.js dashboard for image upload, inference, and visualization, supported by Jupyter-based experiments.

**Technologies:** Python, PyTorch, Torchvision, ResNet18, Grad-CAM, Jupyter, FastAPI, Next.js, TypeScript.

*This project is for educational and research purposes only. It is not clinically validated and must not be used to make medical decisions.*

### 3. [Plant Disease Detection Using Deep Learning](https://github.com/XxCPH4xX/plant-disease-detection-using-deep-learning)

A CNN-based image classification project for identifying plant leaf diseases across **38 classes and 14 plant species**.

- **Model development:** A TensorFlow/Keras CNN with image preprocessing and a documented training workflow.
- **Evaluation:** Training and evaluation notebooks with accuracy visualizations, a confusion matrix, and a classification report.
- **Interface:** Streamlit application for uploading leaf images and viewing predicted classes.
- **Dataset:** The repository documents a dataset of approximately 87,000 images.

**Technologies:** Python, TensorFlow, Keras, NumPy, scikit-learn, Matplotlib, Streamlit, Jupyter.

### 4. [HandSign Detection](https://github.com/XxCPH4xX/HandSign-Detection)

A real-time webcam application that recognizes a limited set of hand signs using computer vision and a trained classification model.

- **Real-time processing:** Webcam input and hand detection with OpenCV and MediaPipe through cvzone.
- **Data collection:** Capture and organize custom hand-sign training images.
- **Classification:** TensorFlow/Keras model with hand-region cropping and image preprocessing.
- **Supported signs:** `I`, `L`, `O`, `V`, `E`, and `U`.

**Technologies:** Python, OpenCV, MediaPipe, cvzone, TensorFlow, Keras, NumPy.

### 5. [Smart Attendance System Using Face Recognition](https://github.com/XxCPH4xX/smart-attendance-system-using-face-recognition)

A webcam-based attendance application that identifies registered faces and records attendance with timestamps.

- Detects faces in live video using OpenCV-based image processing.
- Matches detected faces against registered face encodings using the `face_recognition` library.
- Displays recognized identities and labels unknown faces.
- Records attendance in a CSV file for subsequent review.

**Technologies:** Python, OpenCV, face_recognition, dlib, NumPy.
